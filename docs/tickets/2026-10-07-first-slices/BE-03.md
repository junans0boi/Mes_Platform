# BE-03: 백엔드 기반 3/4: JWT, Permission Code, Plant 범위

상태: 완료(로컬 검증, 2026-10-07)  /  선행: BE-02, CON-01  /  Gate: integration

## 목적

임시(provisional) login·session 계약(CON-01), JWT 인증, Permission Code, 명시적 `plantId`와 `allowedPlantIds` 검증을 구현한다. BE-05(refresh·logout·cookie 결정)를 기다리지 않는다.

## 범위

- plan Task 6
- `POST /api/v1/auth/login`(access token만 반환)과 `GET /api/v1/auth/session`(user, `allowedPlantIds`, capabilities)을 CON-01 임시 계약대로 구현
- `IUserAuthenticator` seam과 Development 전용 설정 기반 구현(운영 환경에서 활성화되면 시작 거부). 실제 사용자·권한 저장소는 후속
- `RequirePermission` 속성과 Plant 범위 검증(Query·Command 모두 명시된 plantId를 `allowedPlantIds`와 대조, 불허 시 403)

## 제외 범위

- refresh token, cookie, rotation, 재사용 감지, logout, CORS 정책(BE-05 결정, BE-11 구현)
- 실제 사용자·권한 저장소와 사용자 관리 UI
- 임시 계약의 필드 변경(CON-02 경유)

## 관련 API/계약

`contracts/openapi.yaml`(CON-01 login·session), docs/plans/backend/2026-10-07-mes-platform-backend-foundation-plan.md Task 6, docs/specs/backend/2026-10-07-mes-platform-backend-design.md §15

- [x] session이 user, `allowedPlantIds`, capabilities를 반환하고 응답이 CON-01과 일치한다
- [x] 토큰 없음·만료는 401, Permission·Plant 부족은 403이다
- [x] 허용되지 않은 `plantId` 요청이 403이다
- [x] 헤더로 숨겨진 Plant 지정이 없다
- [x] Development 전용 `IUserAuthenticator`가 운영 환경 설정에서 활성화되면 시작이 거부된다

## 완료 기록 (2026-10-07)

- **구현 위치**: `Application/Abstractions/Identity`(`CurrentUserSnapshot`, `IUserAuthenticator`, `PermissionCode`), `Infrastructure/Identity`(Development 전용 설정 기반 `DevelopmentUserAuthenticator`, 운영 환경 거부 validator, 기본 `DisabledUserAuthenticator`), `Server/Authentication`(JWT 옵션·발급·검증), `Server/Authorization`(`RequirePermission`, 동적 policy, handler, `PlantScoped`, `CurrentUserAccessor`), `Server/Controllers/Auth`(login, session), `Server/Errors/ProblemWriter`(401·403·400도 같은 Problem Details).
- **계획 대비 변경**: 계획의 `PermissionAttribute` 이름 대신 티켓·설계 §15.1의 `RequirePermission`을 썼다(`RequirePermissionAttribute`). Plant 검증은 `[PlantScoped]` action filter이며 `plantId` 인자(query·route) 또는 `IPlantScoped` 본문에서만 값을 읽는다.
- **오류 코드**: 401 `AUTHENTICATION_REQUIRED`/`TOKEN_EXPIRED`/`TOKEN_INVALID`/`INVALID_CREDENTIALS`, 403 `PERMISSION_DENIED`(args.permission)/`PLANT_NOT_ALLOWED`(args.plantId), 400 `PLANT_ID_REQUIRED`/`VALIDATION_FAILED`.
- **설정**: `Authentication:Jwt:SigningKey`(32바이트 이상, 저장소에 커밋하지 않음)와 `Authentication:DevelopmentAuthenticator`는 `appsettings.Development.example.json`을 복사해 쓴다. `appsettings.Development.json`은 `.gitignore`에 추가했다.
- **`/api/v1/system/info`**: `System.Info.Read`로 보호했다.
- **검증**: `dotnet test --filter "Category!=SqlIntegration"` — Application 45, Domain 12, Infrastructure 6, Api 46(이 티켓에서 신규 41) 통과. Architecture 9개 중 8개 통과, `Sdk_version_is_pinned`는 이 작업 환경에 SDK 10.0.112만 설치되어 로컬에서만 `global.json`을 임시로 `10.0.100`으로 바꿔(`git update-index --skip-worktree`, 커밋 제외) 실행한 탓에 실패했다. 저장소의 `global.json`은 `10.0.400` 그대로다.
- **남은 것**: 실제 사용자·권한 저장소(후속), refresh·logout·cookie(BE-11). SQL Server가 필요한 `SqlIntegration` 테스트는 이 환경에서 실행하지 않았다.
