# BE-03: 백엔드 기반 3/4: JWT, Permission Code, Plant 범위

상태: 선행 완료 시 착수 가능  /  선행: BE-02, CON-01  /  Gate: integration

## 목적

임시(provisional) login·session 계약(CON-01), JWT 인증, Permission Code, 명시적 `plantId`와 `allowedPlantIds` 검증을 구현한다. BE-05(refresh·logout·cookie 결정)를 기다리지 않는다.

## 범위

- plan Task 6
- `POST /api/v1/auth/login`(access token만 반환)과 `GET /api/v1/auth/session`(user, `allowedPlantIds`, capabilities)을 CON-01 임시 계약대로 구현
- `IUserAuthenticator` seam과 Development 전용 설정 기반 구현(운영 환경에서 활성화되면 시작 거부). 실제 사용자·권한 저장소는 후속
- `RequirePermission` 속성과 Plant 범위 검증(Query·Command 모두 명시된 plantId를 `allowedPlantIds`와 대조, 불허 시 403)

## 제외 범위

- refresh token, cookie, rotation, 재사용 감지, logout, CORS 정책(BE-05 결정, BE-11 구현)
- 실제 사용자·권한 저장소와 사용자 관리 UI
- 임시 계약의 필드 변경(CON-02 경유)

## 관련 API/계약

`contracts/openapi.yaml`(CON-01 login·session), docs/plans/backend/2026-10-07-mes-platform-backend-foundation-plan.md Task 6, docs/specs/backend/2026-10-07-mes-platform-backend-design.md §15

## 관련 화면/모듈

`src/MesPlatform.Server/`, `src/MesPlatform.Infrastructure/`

## 완료 조건

- [ ] login이 access token을 반환하고 refresh token·cookie를 설정하지 않는다
- [ ] session이 user, `allowedPlantIds`, capabilities를 반환하고 응답이 CON-01과 일치한다
- [ ] 토큰 없음·만료는 401, Permission·Plant 부족은 403이다
- [ ] 허용되지 않은 `plantId` 요청이 403이다
- [ ] 헤더로 숨겨진 Plant 지정이 없다
- [ ] Development 전용 `IUserAuthenticator`가 운영 환경 설정에서 활성화되면 시작이 거부된다
