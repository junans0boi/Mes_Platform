# FE-02: 공유 계약 기반 타입 API client(typed client), ApiError mapper, MSW

상태: 완료(로컬 검증, 2026-10-07)  /  선행: FE-01, CON-01  /  Gate: foundation

## 목적

공유 계약(CON-01)을 소비하는 typed client, ApiError mapper, MSW mock 기반을 프론트에 만든다. 계약 파일은 이 티켓이 만들지 않는다.

## 범위

- CON-01의 `contracts/openapi.yaml`에서 `openapi-typescript` 타입 생성 스크립트와 `openapi-fetch` 기반 `platform/api/httpClient.ts`
- `ApiError` mapper: `code,args,errors,requestId,operationId`
- 요청마다 `requestId` 생성·전달, AbortSignal 지원
- `plantId`를 httpClient가 주입하지 않음을 테스트로 고정
- MSW handler를 `contracts/openapi.yaml`에서 만드는 방법 확립

## 제외 범위

- `contracts/openapi.yaml`과 `contracts/realtime-events.md` 작성·수정 (CON-01)
- WorkOrder·ProcessUnitStatus 화면 코드
- refresh·logout endpoint (CON-02, BE-05 확정 후)
- 백엔드 구현

## 관련 API/계약

`contracts/openapi.yaml` (CON-01 소비), docs/specs/backend/2026-10-07-mes-platform-backend-design.md §9.3·§9.4·§17.1

## 관련 화면/모듈

`frontend/mes-web/src/platform/api/`

## 완료 기록 (2026-10-07)

- 타입 생성: `npm run api:generate` → `src/platform/api/generated/schema.d.ts`(수정 금지). `npm run api:check`는 계약과 생성물이 다르면 실패한다(파일은 바꾸지 않음).
- `platform/api/httpClient.ts`: openapi-fetch + middleware. 요청마다 UUID `X-Request-Id`, 있을 때만 `Authorization`, 오류는 `ApiError`로 throw. `plantId`·Plant 헤더 주입 없음.
- `platform/api/ApiError.ts`: kind `badRequest/unauthorized/forbidden/notFound/conflict/unprocessable/server/network/aborted/unexpected`, `code/args/errors[]/requestId/operationId/traceId` 보존.
- `src/test/contractMock.ts`: MSW 기본 handler와 샘플 본문·오류 샘플을 `contracts/openapi.yaml`에서 생성(8개 operation 전부).
- 검증: `npm run typecheck`, `lint`, `format:check`, `test`(6 파일 65 테스트 통과), `api:check`, `build` 통과.
- 범위 밖으로 남긴 것: 401 후 처리·토큰 저장(FE-04), TanStack Query 연결(FE-05 이후).
