# BE-09: 대표 데이터 seed와 서버 성능 측정 도구(performance harness)

상태: 선행 완료 시 착수 가능  /  선행: BE-07, BE-08, DB-01, DB-02  /  Gate: performance

## 목적

WorkOrder·ProcessUnitStatusCurrent 대표 데이터 seed와 서버 p95 측정을 소유한다. BE-07·BE-08의 p95 목표(WorkOrder 300ms, process-unit-status 500ms)는 이 티켓에서 측정한다. ProcessUnitStatusCurrent 행은 계산기를 거치지 않고 seed로 직접 적재하므로 **Projection 계산·갱신 성능은 측정 대상이 아니다**(실제 계산기 구현 후속에서 측정). 100만 건 benchmark는 ProcessResult·EquipmentLog에 대해 별도로 둔다.

## 범위

- WorkOrder 대표 데이터 seed(DB-01 위), ProcessUnitStatusCurrent 대표 데이터 seed(DB-02 위, 운영 분포 근사, 여러 Plant, `ProjectionVersion` 포함)를 SQL로 직접 적재
- 서버 응답시간 p95 측정 스크립트: 목록·검색·정렬·상세, process-unit-status 목록·`ids`(Plant 범위 포함)
- 측정 결과 기록 형식(FE-11이 브라우저 지표와 합쳐 보고서 작성)

## 제외 범위

- ProcessResult·EquipmentLog 100만 건 benchmark(후속 Issue)
- Projection Worker 계산·갱신 처리량 측정(실제 계산기 구현 후속)
- 운영 DB 사용
