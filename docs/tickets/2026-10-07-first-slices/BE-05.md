# BE-05: 결정: 인증 계약 (refresh·logout·cookie)

상태: 선행 완료 시 착수 가능  /  선행: 없음  /  Gate: decision

## 목적

refresh·logout·cookie·rotation·재사용 감지·CORS 정책을 확정한다. 임시(provisional) login·session(CON-01, backend design §15.3)은 이미 확정되어 있으며 이 티켓이 다시 정하지 않는다. 첫 수직 슬라이스(BE-03, FE-04)는 이 티켓을 기다리지 않는다.

## 범위

- refresh·logout endpoint와 요청·응답
- refresh cookie 이름·Path·Domain·SameSite·만료(방향은 HttpOnly+Secure+SameSite 확정, 값은 이 티켓에서 결정)
- rotation과 재사용 감지 시 동작(세션 전체 폐기 여부)
- CORS와 cookie 배포 구성(동일 origin 여부)
- login 응답에 refresh cookie를 설정하는 변경을 임시 계약에 추가형(additive)로 표현하는 방법

## 제외 범위

- 임시 login·session 계약의 재결정(capability·`allowedPlantIds`는 session 조회로 확정)
- 구현(BE-11, FE-13)
