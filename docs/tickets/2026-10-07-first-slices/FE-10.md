# FE-10: 실시간 연결 상태, fallback refresh, asOf 표시

상태: 선행 완료 시 착수 가능  /  선행: FE-09  /  Gate: foundation

## 목적

연결 상태와 fallback refresh를 구현하고 운영자에게 기준 시각과 상태를 보여준다.

## 범위

- 연결 상태(connected/reconnecting/disconnected)와 마지막 이벤트 시각, 마지막 `asOf`, stale 표시를 RealtimeToolbar에 표시
- 연결 해제·재연결 직후 30초 주기(설정값) fallback refresh, 이벤트가 안정되면 중단
- 재연결 시 한 번 전체 재조회
- 상태를 색상 외 텍스트·아이콘으로 표시

## 제외 범위

- 서버 측 이벤트 발행(BE-08)
- 알림 drawer

## 관련 API/계약

docs/specs/frontend/2026-10-07-mes-platform-frontend-design.md §12, §17

## 관련 화면/모듈

`platform/realtime/`, `modules/monitoring/process-unit-status/ui/RealtimeToolbar`

## 완료 조건

- [ ] 연결이 끊기면 사용자에게 상태가 표시되고 fallback refresh가 동작한다
- [ ] 복구되면 fallback이 중단된다
- [ ] projection `asOf`와 브라우저 갱신 시각이 구분되어 표시된다
- [ ] fallback 동안 전체 목록 polling이 설정된 주기를 넘지 않는다

## 테스트 방법

Playwright(mock hub 끊김·복구), Vitest(fake timer)

## 완료 증거

Playwright 결과, 요청 간격 로그
