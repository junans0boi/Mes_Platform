# BE-02: 백엔드 기반 2/4: Infrastructure seam, Server host, envelope, Problem Details

상태: 선행 완료 시 착수 가능  /  선행: BE-01, CON-01  /  Gate: foundation

## 목적

SQL Server·Dapper seam과 Server 호스트, 성공 envelope, Problem Details(`args`,`errors`)를 구현한다.

## 범위

- plan Task 4~5
- `ApiEnvelope<T>{data,meta}`, `PageResponse<T>`는 envelope의 data
- Problem Details: `code,args,errors[{field,code,args}],requestId,operationId,traceId`
- Cursor 규칙(`CURSOR_SORT_MISMATCH`)의 공통 구현
- OpenAPI 문서 생성. CON-01 계약과 다른 응답 형태를 만들지 않는다(envelope, Problem Details, cursor는 계약 그대로)

## 제외 범위

- 업무 endpoint(BE-07, BE-08)
