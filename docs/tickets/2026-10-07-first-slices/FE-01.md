# FE-01: frontend/mes-web 프로젝트와 빌드 도구(toolchain) 구성

상태: 선행 완료 시 착수 가능  /  선행: 없음  /  Gate: foundation

## 목적

frontend/mes-web을 만들고 이후 모든 프론트 티켓이 사용할 빌드·검사 기반을 마련한다.

## 범위

- Vite + React + TypeScript 프로젝트 (npm, lockfile 고정)
- ESLint, Prettier, Vitest, Playwright, MSW 설정
- 환경 설정(API·Hub URL, dev proxy), `.env.example`(키 이름만)
- MUI X 라이선스 키는 `.env.local`로만 주입, 커밋하지 않음
- `.github/workflows/frontend.yml`: typecheck, lint, test, build, bundle 크기 기록
- README에 실행 방법 추가

## 제외 범위

- 화면, 라우팅, API client, 인증 (FE-02~04)
- zustand 등 설계에서 제외한 의존성
- 백엔드 CI

## 관련 API/계약

없음 (npm scripts: typecheck, lint, test, build, e2e)

## 관련 화면/모듈

`frontend/mes-web/` (설정 파일만), `.github/workflows/frontend.yml`, `README.md`

## 완료 조건

- [ ] `npm ci && npm run typecheck && npm run lint && npm run test && npm run build`가 로컬과 CI에서 통과한다
- [ ] 빈 앱이 `npm run dev`로 뜨고 Playwright smoke 1개가 통과한다
- [ ] 라이선스 키·`.env.local`이 git에 포함되지 않는다
- [ ] 빌드 산출물의 gzip 크기가 CI 로그에 기록된다
- [ ] `node scripts/agent-check.mjs` 통과

## 테스트 방법

CI 실행, 로컬 명령, `git check-ignore`로 `.env.local` 확인

## 완료 증거

CI 실행 링크, 빌드 크기 로그, 명령 출력
