# DB-02: ProcessUnitStatusCurrent, ProjectionVersionSeq, ProcessStatusRefreshQueue, ProjectionChangeOutbox와 index

상태: 선행 완료 시 착수 가능  /  선행: DB-01, BE-12  /  Gate: integration

## 목적

BE-08이 사용할 Projection 읽기 모델, version·Queue 스키마, 변경 알림 Outbox 스키마를 제공한다. Outbox 정책 값은 BE-12 결정을 따른다.

## 범위

- `dbo.ProcessUnitStatusCurrent`: `ProcessUnitStatusId`(bigint identity, PK), **`PlantId int NOT NULL`**(`dbo.Plant.PlantId`와 동일한 타입, `dbo.Plant` FK), `ProductionLotId`+`HousingQr` UNIQUE, `ProjectionVersion`(bigint), `LastUpdatedAt` 등 database design §4.8 컬럼
- `ProductionLotId`, `ProductModelId`, `LastProcessResultId`는 원본 테이블이 아직 없으므로 FK 없는 bigint 컬럼(FK는 원본 테이블 티켓에서 추가)
- `dbo.ProjectionVersionSeq`: `AS bigint START WITH 1 INCREMENT BY 1 MINVALUE 1 MAXVALUE 9007199254740991 NO CYCLE`(API가 JSON 정수로 전송하므로 브라우저 안전 정수 상한을 둔다)
- `ProcessUnitStatusCurrent` NULL 허용·기본값은 database design §4.8 표를 따른다(`IsInProgress`·`IsScrapped`·`ProcessSkip` bit NOT NULL 기본 0, `ScrapCount` int NOT NULL 기본 0, `FinalResult`·`LastProcessAt`·`LastProcessCode`·`ProductModelId`·`LastProcessResultId` NULL 허용)
- `dbo.ProcessStatusRefreshQueue`: `ProcessStatusRefreshQueueId`, **`PlantId int NOT NULL`**(`dbo.Plant` FK), `ProductionLotId`, `HousingQr`(NULL이면 LOT 단위), `Status`, `EnqueuedAt`, `ClaimedAt`, `ClaimedBy`, `AttemptCount`, `LastError`
- ProcessUnitStatusCurrent index(database design §4.8·§8과 동일, `PlantId` 선행): `ProcessUnitStatusId` PK, `(PlantId, LastUpdatedAt DESC, ProcessUnitStatusId DESC)`(sort=lastUpdatedAt), `(PlantId, LastProcessAt DESC, ProcessUnitStatusId DESC)`(sort=lastProcessAt), `(PlantId, FinalResult, LastUpdatedAt DESC, ProcessUnitStatusId DESC)`(finalResult 필터 + 기본 정렬), `(PlantId, FinalResult, ProcessUnitStatusId)`(sort=finalResult). Queue `(Status, EnqueuedAt)`, `(PlantId, Status, EnqueuedAt)`
- `PlantId` 없는 `(FinalResult, LastUpdatedAt)` index는 만들지 않음
- `dbo.ProjectionChangeOutbox`(database design §4.9): `ProjectionChangeOutboxId`(bigint identity PK), **`PlantId int NOT NULL`**(`dbo.Plant` FK), `Projection`, `IsReset`, `ChangedIdsJson`(`IsReset=1`이면 NULL), `AsOf`(UTC), `Status`(Pending/Published/Failed), `AttemptCount`, `NextAttemptAt`, `LeaseOwner`, `LeaseExpiresAt`, `OperationId`(uniqueidentifier NULL), `EnqueuedAt`, `PublishedAt`, `LastError`
- Outbox index: `(Status, NextAttemptAt, ProjectionChangeOutboxId)`(Dispatcher claim), `(PlantId, ProjectionChangeOutboxId)`
- lease·backoff·최대 시도·보관 기간은 backend design §13.4.1(BE-12 확정)의 설정값이다(DDL에 하드코딩하지 않음)
- Upsert, version 기록, Outbox Insert를 같은 transaction에서 하기 위한 DB 객체(필요 시 procedure)

## 제외 범위

- Projection Worker·Outbox writer·Dispatcher 로직과 이벤트 발행(BE-08)
- SignalR backplane
- TVF 재계산 구현
- 대표 데이터 seed(BE-09)
- ProductionLot, ProductModel, ProcessResult 등 원본 테이블과 그에 대한 FK(후속)

## 완료 조건

- [ ] 스크립트가 DB-01 위에 순서대로 적용되고 재실행해도 안전하다
- [ ] `ProcessUnitStatusCurrent.PlantId`, `ProcessStatusRefreshQueue.PlantId`, `ProjectionChangeOutbox.PlantId`가 `int NOT NULL`이고 `dbo.Plant.PlantId`와 타입이 같으며 `dbo.Plant` FK가 있다(존재하지 않는 Plant 삽입 시 실패하는 테스트)
- [ ] Plant 선행 index 4종(lastUpdatedAt, lastProcessAt, finalResult 필터 + 기본 정렬, finalResult 정렬)이 존재하고, API 허용 sort 3종(`lastUpdatedAt`, `lastProcessAt`, `finalResult`)과 `finalResult` 필터 Query가 각각 해당 index를 사용한다(실행 계획 검증)
- [ ] `ProjectionVersionSeq`가 `MAXVALUE 9007199254740991 NO CYCLE`이고 상한 도달 시 오류가 난다(테스트에서 `RESTART WITH` 후 확인)
- [ ] 열 NULL 허용·기본값이 database design §4.8 표와 일치한다(`IsInProgress`·`IsScrapped`·`ProcessSkip`·`ScrapCount`는 NOT NULL)
- [ ] `ProjectionChangeOutbox`가 BE-12가 정한 컬럼(Plant, projection, `changedIds` 또는 reset, `asOf`, 상태, attempt count, lease, `PublishedAt`, `LastError`)을 모두 갖고 Dispatcher claim용 index가 있다
- [ ] **Projection 행 Upsert, `ProjectionVersion` 기록, Outbox Insert가 같은 transaction이다**: 통합 테스트에서 Outbox Insert 실패 시 Projection 행·version도 rollback되고, Projection Upsert 실패 시 Outbox 행이 남지 않는다
- [ ] `ProjectionVersionSeq`에서 얻은 값이 행의 `ProjectionVersion`에 기록된다
- [ ] 같은 행의 `ProjectionVersion`이 갱신마다 증가한다
- [ ] `ProjectionVersion` 컬럼은 `rowversion` 타입이 아니라 bigint다(WorkOrder `RowVersion`과 혼동하지 않는다)
- [ ] Queue Claim용 컬럼과 index가 있다
- [ ] `IsReset=1`인 행은 `ChangedIdsJson`이 NULL이다(제약 또는 검증 테스트)
