# FE-08: ProcessUnitStatus 조회와 1-2 실시간 공정 화면 (데이터 조회만)

상태: 선행 완료 시 착수 가능  /  선행: FE-04, FE-05, CON-01  /  Gate: foundation

## 목적

`process-unit-status` 공통 query와 Kdit 1-2 대체 화면의 조회 부분을 만든다. 실시간 갱신은 FE-09·FE-10이다.

## 범위

- CON-01의 `GET /api/v1/monitoring/process-unit-status`(cursor, sort, `plantId`)와 `?ids=` 일괄 조회(상한 100) 계약을 소비, 행의 `projectionVersion`, 응답의 `asOf`
- `modules/monitoring/process-unit-status` 모듈: route, 공용 query adapter, 모델, StatusSummaryStrip, RealtimeDataGrid, DetailDrawer
- `asOf` 표시와 브라우저 조회 시각 구분
- capability `Monitoring.ProcessUnitStatus.Read`

## 제외 범위

- SignalR와 coordinator(FE-09)
- 연결 상태·fallback(FE-10)
- 4-6·4-7·7-3 화면
- Kdit 1-2의 편집 Command·QR·layout 편집

## 관련 API/계약

Contract: CON-01의 `GET …/process-unit-status`, docs/specs/frontend/2026-10-07-mes-platform-frontend-design.md §9.4, §19 Slice C, docs/specs/database/2026-10-07-mes-platform-database-design.md §4.8

## 관련 화면/모듈

`frontend/mes-web/src/modules/monitoring/process-unit-status/`

## 완료 조건

- [ ] 목록이 cursor로 조회되고 한 번에 200개를 넘지 않는다
- [ ] `ids` 일괄 조회 adapter가 100개 상한으로 분할한다
- [ ] 행에 `projectionVersion`이 보존된다
- [ ] `asOf`가 표시되고 브라우저 조회 시각과 구분된다
- [ ] 화면 코드에 DB 테이블명이 없다
