# FE-13: 인증 silent refresh

상태: 차단됨 (보류(Deferred))  /  선행: FE-04, BE-11, CON-02  /  Gate: deferred

## 목적

확정된 인증 계약에 따라 access token silent refresh와 실패 시 로그인 이동을 구현한다.

## 범위

- access token 만료 시 refresh 호출(HttpOnly+Secure+SameSite cookie, rotation)
- 동시 401에서 refresh 1회 공유
- refresh 실패 시 로그인 이동
- 새로고침 시 세션 복원(refresh로)

## 제외 범위

- refresh 계약의 프론트 임의 추측
- 로그인 UI 변경

## 관련 API/계약

Contract: BE-05가 확정하는 refresh·logout (login·session은 CON-01 임시(provisional)), docs/specs/backend/2026-10-07-mes-platform-backend-design.md §15.3·§24.1

## 관련 화면/모듈

`platform/auth/`

## 완료 조건

- [ ] 새로고침해도 유효한 refresh cookie가 있으면 재로그인 없이 복원된다
- [ ] refresh 실패 시 로그인 화면으로 이동한다
- [ ] 동시 요청 401에서 refresh 호출이 1회다
- [ ] refresh 재사용(rotation 위반) 응답을 로그인 이동으로 처리한다

## 테스트 방법

Vitest, Playwright(mock과 실제 인증 서버)

## 완료 증거

결과 링크

## 차단 조건

BE-05(인증 계약 결정), CON-02(계약), BE-11(refresh 구현) 완료 전에는 착수하지 않는다. 보류.
